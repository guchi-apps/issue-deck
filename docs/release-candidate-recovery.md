# 停止したリリース候補を作り直す

候補の管理記録とブランチの先端が食い違う場合、古い結果を合格として使わない。
修正済みPRをdevelopへマージした後、候補PR詳細の「候補を取り消して作り直す」から既存候補を終了し、ブランチ画面で新しい候補を作る。

この操作はレビュー段階で修正が必要または修正中の候補だけに表示する。修正が既にdevelopへ入っていて修正系列だけが残る場合も、候補を正規に終了できる。公開まで進める系列は先に停止する。既存の取消APIが認証・段階の一致・取消可否を再確認する。
取消は本番公開ではない。履歴・過去の検証結果・ブランチを残し、新しい候補では統合検証と全体レビューをやり直す。
公開準備以降の候補にはこの操作を出さない。
