## 出力言語

出力言語は日本語です。コード・識別子・ファイルパス・コマンド・設定値・ログやエラーメッセージの引用は原文のままで構いません。

## 対象

- リポジトリ: {{REPOSITORY}}
- Pull Request: #{{PR_NUMBER}}
- 比較元SHA: {{BASE_SHA}}
- 対象SHA: {{HEAD_SHA}}

`git diff {{BASE_SHA}}...{{HEAD_SHA}}` の差分と、その周辺コードだけを確認してください。変更前からある問題、推測だけの指摘、好みの問題は指摘しません。

## 観点

- 正しさ、セキュリティ、性能、保守性、テスト漏れのうち、Pull Requestで新たに生じた具体的な問題だけを探す。
- 指摘には、再現または問題になる理由と、対象ファイル・行番号を必ず添える。
- 問題が無い場合は、簡潔にその旨を述べる。

## 出力形式

次の3種類のいずれかを選び、回答の末尾に**必ず1行だけ**対応する判定マーカーを付けてください。`{{HEAD_SHA}}`は変更しません。

- 問題なし: `lgtm`
- 人の確認が必要な懸念: `needs-check`
- 修正すべき問題: `changes-requested`
